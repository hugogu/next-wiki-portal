可选的[飞书](https://open.feishu.cn/)集成让用户在飞书内绑定 Wiki 账号、基于知识库提问、接收事件通知。

## 设计原则

- **进程内模块** —— 运行在 Web 应用内部：不需要独立容器、进程或 Compose profile。
- **未配置前完全惰性** —— 默认的 `docker compose up` 不变，也不需要任何飞书变量。
- **同一套权限模型** —— 机器人的每个动作都归属于绑定的 Wiki 用户，并经过与 Web UI 相同的权限检查。

## 配置

全部在管理界面 `/admin/feishu` 完成：

1. 在 `/admin/feishu` 扫描飞书原生二维码流程，关联已有应用或创建新应用 —— 无需手动复制 App Secret。
2. 凭据与短期 device code **加密存储在 PostgreSQL 中**，永远不会返回给浏览器或写入日志。
3. 机器人通过**出站 WebSocket 长连接**接收事件 —— 不需要回调 URL，也不需要公网入口配置。

## 用户能获得什么

- 飞书与 wiki 账号绑定
- 基于知识库的问答与**工具调用回合** —— 归属于绑定用户，经过与 Web UI 相同的权限检查
- 事件通知（页面更新、提及）推送到飞书
